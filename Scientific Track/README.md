# Phase Transitions in the 1D ANNNI Model under Depolarizing Noise via Quantum Convolutional Neural Networks

## Project Overview
This repository contains my independent research project for the Quantum Coalition QSITE 2026 Hackathon (Scientific Track)[cite: 2]. 
The primary objective is to investigate the 1D ANNNI (Axial Next-Nearest-Neighbor Ising) model using the PennyLane framework, mapping out the phase boundaries of four quantum phases (ferromagnetic, antiphase, paramagnetic, and floating) across the \((\kappa, h)\) parameter plane[cite: 2]. Additionally, this project explores how physical hardware noise—specifically depolarizing noise at levels \(p=0.01\) and \(p=0.05\)—distorts these quantum phase boundaries[cite: 2].

## Methodology & Research Plan
The research is structured into the following core phases:
* **Establishing the Ground Truth**: Utilizing exact diagonalization tools to compute the ground state energies over a fine 20x20 \((\kappa, h)\) parameter grid in a noiseless environment (\(p=0\)), extracting standard classification labels for the four physical phases (ferromagnetic, antiphase, paramagnetic, and floating)[cite: 1, 3].
* **Quantum Convolutional Neural Network (QCNN)**: Leveraging Object-Oriented Programming (OOP) to build parameterized QCNN variational quantum circuits[cite: 1]. This supervised learning approach allows the model to automatically learn and detect the phase boundaries of the 1D ANNNI model[cite: 1, 3].
* **Noise Analysis & Error Mitigation**: Introducing depolarizing noise (\(p=0.01, 0.05\)) into the simulated hardware to analyze how noise blurs and distorts phase diagrams[cite: 1, 3]. I will implement error mitigation techniques (e.g., Zero-Noise Extrapolation) to recover clear physical signals from noisy data[cite: 1, 3].
* **Cross-Method Comparison**: Overlaying phase diagrams generated by QML algorithms against the exact diagonalization baselines to evaluate QCNN robustness under noise[cite: 1, 3]. The final findings will be synthesized into a 2–3 page academic writeup[cite: 1].

## Repository Structure
This project abandons traditional single-script workflows in favor of a modular architecture that adheres to modern software engineering standards[cite: 1]:
* `src/`: Standalone Python modules containing the Hamiltonian Builder, QCNN architectures, and error mitigation logic[cite: 1].
* `notebooks/`: Jupyter Notebooks (e.g., `01_Phase_Detection_Model.ipynb`) for interactive experiments, generating parameter grids, and plotting heatmaps[cite: 1, 3].
* `data/`: Arrays of physical labels generated by exact diagonalization and other reproducible experimental results[cite: 1].
* `Q_SITE_2026_ANNNI_Phase_Detection_Report.pdf`: The final 2-3 page academic report (Writing Sample) detailing the physical phenomena, phase diagrams, and error analysis[cite: 1].
