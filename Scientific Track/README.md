# Phase Transitions in the 1D ANNNI Model under Depolarizing Noise via Quantum Convolutional Neural Networks

## Project Overview
This repository contains my independent research project for the Quantum Coalition QSITE 2026 Hackathon (Scientific Track)[cite: 2]. 
The primary objective is to investigate the 1D ANNNI (Axial Next-Nearest-Neighbor Ising) model using the PennyLane framework, mapping out the phase boundaries of four quantum phases (ferromagnetic, antiphase, paramagnetic, and floating) across the \((\kappa, h)\) parameter plane[cite: 2]. Additionally, this project explores how physical hardware noise—specifically depolarizing noise at levels \(p=0.01\) and \(p=0.05\)—distorts these quantum phase boundaries[cite: 2].

Driven by my interdisciplinary background in Mathematics/Physical Sciences and a Computer Science minor, this project not only tackles quantum many-body physics but also demonstrates rigorous software engineering and data pipeline construction. It serves as a foundational step and a technical writing sample for future independent astrophysics and computational physics research (e.g., CTA495).

## Methodology & Research Plan
The research is structured into the following core phases:
* **Establishing the Ground Truth**: Utilizing exact diagonalization tools to compute the ground state energies over a fine 20x20 \((\kappa, h)\) parameter grid in a noiseless environment (\(p=0\)), extracting standard classification labels for the four physical phases[cite: 2].
* **Quantum Convolutional Neural Network (QCNN)**: Leveraging Object-Oriented Programming (OOP) to build parameterized QCNN variational quantum circuits. This supervised learning approach allows the model to automatically learn and detect the phase boundaries of the 1D ANNNI model[cite: 2].
* **Noise Analysis & Error Mitigation**: Introducing depolarizing noise (\(p=0.01, 0.05\)) into the simulated hardware to analyze how noise blurs and distorts phase diagrams[cite: 2]. I will implement error mitigation techniques (e.g., Zero-Noise Extrapolation) to recover clear physical signals from noisy data[cite: 2].
* **Cross-Method Comparison**: Overlaying phase diagrams generated by QML algorithms against the exact diagonalization baselines to evaluate QCNN robustness under noise[cite: 2]. The final findings will be synthesized into academic writeup[cite: 2].

## Repository Structure
This project abandons traditional single-script workflows in favor of a modular architecture that adheres to modern software engineering standards:
* `src/`: Standalone Python modules containing the Hamiltonian Builder, QCNN architectures, and error mitigation logic.
* `notebooks/`: Jupyter Notebooks (e.g., `01_Phase_Detection_Model.ipynb`) for interactive experiments, generating parameter grids, and plotting heatmaps[cite: 2].
* `data/`: Arrays of physical labels generated by exact diagonalization and other reproducible experimental results.
* `pyproject.toml` & `uv.lock`: Environment configuration files ensuring that anyone pulling this code can deploy the required environment with zero errors[cite: 2].
